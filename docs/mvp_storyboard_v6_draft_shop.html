v6 스토리보드 초안 (3/5): 시공업체

시공업체는 신차인도서비스와 무관하게, 신차 케어 서비스 계약을 고객과 직접 진행한다. 카마스터와 달리 현대기아 소속 영업사원이 아니므로 온라인에서 바로 검색·선택·견적 협의가 가능하다.

이 파일도 검토용 초안입니다. 배송기사·관리자는 다음 단계에서 추가합니다.

PHASE 0

로그인

1
시공업체

로그인 — 사업자 연락처 입력

실제 서비스와 같은 모양으로, 등록된 사업자 연락처로 로그인한다. 매장 카드를 늘어놓고 고르던 이전 방식은 테스트 편의용 드롭다운("테스트 계정으로 빠른 로그인")으로 옮겼다.

PHASE 2

신차 케어 서비스 — 시공업체 파트

2
시공업체

견적 요청 확인

고객이 고른 패키지·옵션·요청사항을 보고 최종 견적가를 정한다.

3
시공업체

고객 확인 대기

견적을 회신한 뒤에는 고객이 확인할 때까지 기다린다.

4
시공업체

계약 완료 — 입고 확인 필요

고객이 견적을 확인하면 계약이 완료되고 "계약완료 — 입고 대기" 목록에 뜬다. 그 차가 신차인도서비스 배송에 얹혀 왔는지, 고객이 나중에 직접 몰고 왔는지는 상관하지 않는다 — 시공사가 스스로 "입고 확인"을 눌러야 다음 단계로 넘어간다(자동 감지 없음).

5
시공업체

입고완료 → 작업중

입고 확인 직후 상태가 "입고완료"로 바뀌고, 그때부터 작업 단계로 직접 넘긴다.

6
시공업체

현장 사진 업로드

작업 진행 중 현장 사진을 최대 3장까지 올릴 수 있다.

7
시공업체

작업완료 — 청구액 입력

정찰가·추가금액·작업 내역을 나눠서 한 번에 기록하고 고객 검수를 요청한다.

8
시공업체

고객 검수 대기

오너가 먼저 확인해야 출차가 진행된다 — 시공업체가 임의로 완료 처리할 수 없다.

9
시공업체

배송 시작 (오너에게)

고객 검수(출차 승인)가 끝나면 배송기사를 배정해 오너에게 배송한다. 이 화면의 문구를 "재배송 대기중"에서 "배송 대기중"으로 정정했다 — 시공업체 입장에서는 처음 발생하는 배송이라 "재"라는 표현이 혼란스러웠다.

10
시공업체

배송 시작 후 — 진행 현황으로 자동 전환

버그 수정: 이전에는 이 버튼을 클릭한 뒤에도 계속 활성 상태로 남아, 반복 클릭 시 배송기사가 계속 재배정되고 처리 이력에 중복 로그가 쌓였다. 이제 배송이 시작되면(transit.active) 버튼 대신 진행 현황 카드로 즉시 전환되어 다시 누를 수 없다.

11
시공업체

처리 완료 — 오너 수령확인 여부

신규 추가: 지금까지는 "처리 완료" 건수 KPI만 있고 실제 목록이 없어, 차를 넘긴 뒤 고객이 무사히 수령확인까지 마쳤는지 시공업체가 확인할 방법이 없었다. 대시보드 맨 아래에 오너 수령확인 완료/대기 상태를 보여주는 리스트를 추가했다.
